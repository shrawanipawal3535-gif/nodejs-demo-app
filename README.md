# Node.js Demo App - CI/CD Pipeline

This repository contains Task 1 for the Elevate Labs DevOps Internship.

## What was done:
* Created a simple Node.js web application.
* Wrote a `Dockerfile` to containerize the application.
* Configured a GitHub Actions CI/CD pipeline (`.github/workflows/main.yml`) to automatically build the Docker image and push it to DockerHub whenever code is pushed to the `main` branch.
